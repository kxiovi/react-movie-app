# Future Reference
## Steps to initialize
(in WebStorm)
```aiignore
npm create vite@latest
```
Name the project `frontend`.

Install all the packages. 
```aiignore
cd frontend/
npm install
```

To run the development server:
```aiignore
npm run dev
```

To specifically navigate to certain pages,
e.g. localhost:xxxx/home or localhost:xxxx/favourites: 
```aiignore
npm install react-router-dom
```
